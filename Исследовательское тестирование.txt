📦 Приложение Пиццерия (Исследование)
│
├── 📁 1. Регистрация (новый пользователь)
│   ├── Поле "Имя"
│   │   ├── Валидное (буквы, кириллица/латиница)
│   │   ├── Невалидное (цифры, спецсимволы)
│   │   └── Границы (1 символ, 50+ символов, пробелы)
│   ├── Поле "Почта" (Email)
│   │   ├── Валидный формат (name@domain.ru)
│   │   ├── Невалидный (без @, без точки, пробелы)
│   │   └── Уникальность (повторная регистрация)
│   ├── Поле "Пароль"
│   │   ├── Валидный (>= 8 символов, сложность)
│   │   ├── Невалидный (короткий, только цифры/буквы, спецсимволы)
│   │   └── Повторный ввод (подтверждение пароля, если есть)
│   └── Отправка формы
│       ├── Успешная регистрация (редирект, письмо на почту)
│       └── Ошибки (понятные сообщения, сохранение данных)
│
├── 📁 2. Вход (Login)
│   ├── Поле "Почта" / "Логин"
│   │   └── Проверка на существующего пользователя
│   ├── Поле "Пароль"
│   │   ├── Валидный пароль → вход выполнен
│   │   └── Невалидный пароль → ошибка
│   └── Восстановление пароля
│       └── Работает ли ссылка "Забыли пароль?"
│
├── 📁 3. Каталог / Меню (Выбор пиццы)
│   ├── Отображение списка пицц
│   │   ├── Все ли позиции видны?
│   │   └── Корректные цены, названия, картинки
│   └── Поиск
│       ├── Поиск по названию (например, "Маргарита")
│       └── Поиск по некорректному запросу (результаты 0)
│
├── 📁 4. Корзина
│   ├── Добавление товара
│   │   ├── Из главного меню
│   │   └── Из карточки товара
│   ├── Редактирование корзины
│   │   ├── Увеличение/уменьшение количества
│   │   └── Удаление товара
│   └── Пересчет итоговой суммы
│
├── 📁 5. Оформление заказа (Checkout)
│   ├── Адрес доставки
│   │   ├── Валидный адрес
│   │   └── Невалидный (пустое поле, отсутствие города/улицы)
│   ├── Способ оплаты
│   │   ├── Наличные / Карта онлайн
│   │   └── Проходит ли оплата (в тестовом режиме)
│   └── Подтверждение заказа
│       ├── Кнопка "Оформить" активна
│       └── После заказа — появление номера заказа и статус
│
└── 📁 6. Личный кабинет (Профиль)
    ├── История заказов
    │   └── Отображаются ли прошлые заказы с деталями
    ├── Изменение данных
    │   └── Смена имени, почты, пароля
    └── Выход из аккаунта (Logout)
        └── Сессия завершена
